# Marque BuyFit

Charte v1 (logo, couleurs, typographie), partagée entre le site (`apps/web`) et l'extension.
Le site l'applique via `apps/web/app/globals.css` et la présente sur la page `/design`.

| Fichier                   | Contenu                                                            |
| ------------------------- | ------------------------------------------------------------------ |
| `logo-mark.svg`           | La marque seule (le « b »), bordeaux                               |
| `logo-wordmark.svg`       | Logotype « buyfit » (texte en Inter Bold : Inter doit être chargé) |
| `icon-{16,32,48,128}.svg` | Icônes d'application / d'extension Chrome                          |
| `palette.json`            | Couleurs, typographie et rayons (lisible par du code)              |
| `tokens.css`              | Les mêmes valeurs en variables CSS `--bf-*`                        |

Slogan : **If you love this fit, buy it**.

## Règles

- Bordeaux `#7A1F2B` pour la marque et les actions principales ; `#5C1420` au survol / à l'appui.
- Rose poudré `#F3D6DB` pour les sélections, avec du texte `#5C1420` dessus.
- Fond blanc, surfaces en lin `#F7F5F2`, beaucoup de blanc.
- Inter partout. Rayons : 12 px (éléments, cartes), 16 px (panneaux).
- Icône : carré bordeaux, coins à ~22 % du côté, marque blanche (traits 24 / 12, ou 30 / 15 sous 32 px).
