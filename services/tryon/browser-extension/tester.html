Comment démarrer le serveur ?

Dans le terminal du projet, active l’environnement Python et lance le service. Garde ce terminal ouvert pendant le test.

cd /Users/felixmachenaud/eugenia/hackathon/buyfit/services/tryon
source .venv/bin/activate
python -m uvicorn app:app --host 127.0.0.1 --port 8000 --no-access-log

Le mode dépend des variables de ce terminal. Sans moteur local installé, utilise le mode Hugging Face décrit dans le README du service, ou le mode simulation pour vérifier l’affichage.
